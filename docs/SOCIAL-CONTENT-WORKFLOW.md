# 社群貼文與圖片工具

- 入口一：文章提示詞／預覽頁的第 4 區，可直接使用目前預覽文章。
- 入口二：文章工作臺首頁的「社群貼文／圖片工具」，可貼公開網址或文章全文。
- Facebook 預設勾選；Facebook、Instagram、Threads 依各平台的開頭、長度、互動與 Hashtag 規則分別重寫。
- 可選專業可信、溫暖關懷、故事共鳴、反差吸睛、精簡俐落，以及每篇 0–8 個 Emoji。
- 圖片是瀏覽器即時產生的品牌文字圖，可切換 1:1 或 4:5，支援複製圖片與下載 PNG，不呼叫額外圖片 AI。
- 公開網址由伺服器擷取，阻擋 localhost、私人 IP、非 HTTP(S)、非文字頁、超大頁面及過多重新導向。讀取失敗時改貼文章內容。
- 只生成發布素材，不會自動登入或發布到任何社群帳號。
- 社群生成每日台灣時間最多 30 次；包含上游模型失敗的請求。
